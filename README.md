# R7 R8 Headphone Control
_A professional headphone management app by Totamo Studio._

---

## 🎧 Overview
**R7 R8 Headphone Control** is a powerful and intuitive app designed to manage and customize your R7 and R8 series headphones.  
Connect seamlessly via Bluetooth, adjust audio settings, update firmware, and personalize your listening experience.

---

## 🎮 Features
- 🔊 Customizable EQ and sound profiles  
- 🔋 Real-time battery status monitoring  
- 🎵 Multiple audio presets (Music, Movie, Gaming, Podcast)  
- 📡 Firmware update support  
- ⚙️ Touch control customization  
- 🎚️ Volume limiter and noise control settings  
- 💎 Premium features for advanced users  
- 🧘 Intuitive and user-friendly interface
